# PSR-175 Coach

A free, single-file web app that teaches songs on a keyboard — built for the
Yamaha PSR-175, usable with any keyboard. Watch mode, play-along, wait-for-me
practice with animated fingering hands, a kid mode, and optional microphone
listening so you can play on the real instrument.

**Use it:** https://nexlcap.github.io/psr175-coach/

## Privacy

- No accounts, no cookies, no analytics, no trackers.
- The only external request is loading two fonts from Google Fonts.
- The microphone is used only if you switch it on, and the audio is analyzed
  entirely on your device to detect pitches — nothing is recorded, stored, or
  sent anywhere.
- Settings and practice stars are kept in your browser's local storage only.

## Songs

All included songs are traditional/public-domain melodies.

## The story

I wanted to learn keyboard together with my child on a two-decades-old
Yamaha PSR-175, handed down from a friend who no longer needed it, using
its built-in learning system — and discovered that
*reading the user manual of a 20-year-old keyboard* is a learning challenge
of its own. So I vibe-coded an interactive manual for it. That worked so
well that I thought: why stop there?

Two days of evening hours later, this web app was on GitHub — complete with
some truly ridiculous-looking hands (they've since been to the beauty salon).
Anyway: my family actually has a lot of fun with it, playing on the tablet
as a virtual keyboard, or using it as a practice assistant next to the real
one, which listens through the microphone.
